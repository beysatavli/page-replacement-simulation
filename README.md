# Page Replacement Simulator

İşletim Sistemleri dersi kapsamında geliştirilen sayfa değiştirme algoritmaları simülasyonu.

## Özellikler

- FIFO (First-In, First-Out)
- LRU (Least Recently Used)
- Optimal Page Replacement
- Second Chance (Clock)
- Page fault ve hit hesaplama
- Adım adım simülasyon geçmişi
- CustomTkinter kullanıcı arayüzü
- Otomatik testler ve girdi doğrulama
